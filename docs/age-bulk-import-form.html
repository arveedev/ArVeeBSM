Bulk Import Latest Known Ages

One warehouse+variety+age(+bags) per line, comma-separated:
Warehouse, Variety, Age in months, Net Bags (optional)
Example:
BSI B, WD1, 2.5, 500
TAB GID, PDm, 8 (bags omitted is fine)
This same data feeds the Daily Inventory spreadsheet's starting balances too, via Config!B6 there - include Net Bags here whenever you have it, rather than entering it again on the other spreadsheet.
