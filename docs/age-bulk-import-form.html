Bulk Import Latest Known Stock (QA)

One warehouse+variety+age-bracket per line, comma-separated:
Warehouse, Variety, Age Bracket, Net Kilos, Net Bags
Fill in EITHER Net Kilos OR Net Bags per line, not both - leave the other blank. Age Bracket matches the QUASAR report's own labels ("0-1.0", "1.1-2.0", "9.1-10.0", ...) - spacing doesn't matter, "9.1 - 10.0" and "9.1-10.0" both work.
Example (a warehouse+variety with stock in 3 different brackets - each gets its own line):
BSI LIBON, PDs, 9.1-10.0, 18646.55,
BSI LIBON, PDs, 10.1-11.0, ,48967.52
BSI LIBON, PDs, 12.1-13.0, 49018.92,
This same data feeds the Daily Inventory spreadsheet's starting balances too, via Config!B6 there - nothing needs to be entered twice.

Set this to the TRUE date the data reflects, not the date you're pasting it in - e.g. if this is a physical count from July 31, enter July 31 here even if you're importing it three weeks later.
