Bulk Import Latest Known Ages

One warehouse+variety+age(+bags) per line, comma-separated:
Warehouse, Variety, Age in months, Net Bags (optional)
Example:
BSI B, WD1, 2.5, 500
TAB GID, PDm, 8 (bags omitted is fine)
This same data feeds the Daily Inventory spreadsheet's starting balances too, via Config!B6 there - include Net Bags here whenever you have it, rather than entering it again on the other spreadsheet.

Set this to the TRUE date the data reflects, not the date you're pasting it in - e.g. if this is a physical count from July 31, enter July 31 here even if you're importing it three weeks later. Both Daily Inventory's starting balances and this report's own baseline-seeding only trust a submission dated on/before their configured start date, so a historical backfill needs its real date to be usable.
